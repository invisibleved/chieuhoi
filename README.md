# Chiếu Hới — gói bàn giao cho phát triển

| Thư mục | Nội dung |
| --- | --- |
| `CLAUDE.md` | Quy tắc dự án — Claude Code tự đọc khi mở thư mục này |
| `docs/HANDOFF.md` | Tài liệu bàn giao (route, token, component, tương tác, CMS, a11y, việc cần xác minh) |
| `docs/KICKOFF_PROMPT.md` | Prompt khởi động theo phase |
| `design/screens/` | Ảnh chụp toàn trang 25 màn hình (desktop 1440, mobile 390) |
| `design/source/` | Mã nguồn artboard `.dc.html` để tra giá trị chính xác |
| `design/explorations/` | 3 hướng thiết kế ban đầu, chỉ để tham khảo |
| `design/tokens/` | `tokens.css`, `tailwind.preset.ts` |
| `design/reference-images/` | Ảnh tham khảo — chưa có quyền đăng (xem `RIGHTS.md`) |
| `content/seed/` | Dữ liệu mẫu JSON có trường nguồn, consent, confidence |

Bản gốc trên claude.ai (riêng tư, cần chia sẻ để người khác xem):
- Canvas: https://claude.ai/artifact/SgNwDLSutHp5F7tWP8TCrv
- Tài liệu bàn giao: https://claude.ai/artifact/QYd3S7KcUHZkg8TCX2gsUZ

## Bắt đầu
1. Giải nén vào một thư mục trống, ví dụ `~/projects/chieu-hoi`.
2. Mở terminal trong thư mục đó và chạy `claude`.
3. Dán nội dung `docs/KICKOFF_PROMPT.md`.
